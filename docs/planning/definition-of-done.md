# Definition of Done

스프린트 항목이 "완료"이려면 아래를 **전부** 만족한다.

## 코드

- [ ] 헥사고날 의존 규칙 위반 없음 (`tests/unit/domain/test_dependency_rule.py` 통과)
- [ ] 도메인 로직은 목(mock) 없이 테스트됨
- [ ] 외부 API 어댑터는 계약 테스트(`tests/contract/`) 존재 — 실제 호출 대신 고정 응답
- [ ] `ruff check` / `mypy --strict` 통과
- [ ] 시크릿이 코드·커밋에 없음

## 설계

- [ ] 되돌리기 어려운 결정은 ADR 로 기록됨 (`docs/architecture/adr/`)
- [ ] 새로 등장한 도메인 용어는 [용어사전](../domain/glossary.md)에 추가됨
- [ ] 포트 시그니처 변경 시 영향받는 어댑터 목록이 PR 에 명시됨

## 검증

- [ ] 해당 스프린트의 "보여줄 수 있는 것"이 실제로 시연됨
- [ ] 실패 케이스 최소 1개가 테스트로 존재 (빈 결과, 외부 API 오류, 권한 없음 등)

## 문서

- [ ] 스프린트 문서의 체크박스가 실제 상태를 반영
- [ ] 다음 스프린트로 넘긴 항목이 명시적으로 기록됨 (조용히 사라지지 않는다)
