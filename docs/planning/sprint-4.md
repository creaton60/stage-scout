# Sprint 4 — 현장 사진 기반 지형 분석

| | |
|---|---|
| 주차 | W4 |
| 담당 요구사항 | FR-4 (현장 사진 지형 분석) |
| 브랜치 | `sprint-4-site-survey` |
| 선행 | S1 SPIKE-2 (정합 검증), S2 (후보지) |

## 목표

**지도가 모르는 것을 사진에서 읽는다.** 지도에는 잔디밭 하나로 보이는 곳에
실제로는 수목 세 그루와 완만한 경사와 전주가 있다. 이 스프린트는 현장 사진을
가용 영역 폴리곤과 장애물 목록으로 바꾼다 — S5 배치 최적화의 제약 조건이 된다.

**이 프로젝트에서 기술 난도가 가장 높은 구간이다.**

## 끝나면 보여줄 수 있는 것

현장 사진 몇 장을 올리면, 지도 위에 "여기는 쓸 수 있고 저기는 나무가 있다"가
폴리곤으로 그려지고 신뢰도가 함께 표시된다.

## 설계 사항

- [ ] **정합 방식 최종 확정** (ADR-0004) — S1 스파이크 결과 반영.
      오차 5m 초과였다면 **수동 폴리곤 편집 중심으로 범위를 축소**하고 ADR 을 대체한다
- [ ] **EXIF 부재 대응 설계** — 방위 정보 없는 사진이 다수일 것으로 예상.
      지도에서 촬영 위치·방향을 사용자가 찍는 UI 를 1급 기능으로 설계
- [ ] **장애물 분류 체계** — 수목/전주/건물/경사/수면. 각각이 배치에 주는 제약이 다르다
- [ ] **신뢰도(confidence) 산출 규칙** — 무엇이 신뢰도를 떨어뜨리는가
      (EXIF 부재, 경사지, 사진 장수 부족). **UI 에 항상 노출** (NFR-4)
- [ ] **다중 사진 병합 규칙** — 여러 장의 분석 결과가 겹칠 때 합집합/교집합 정책
- [ ] **개인정보 처리** (NFR-6) — 사진 속 인물 마스킹 시점, 위치정보 보관 범위, 보존 기간
- [ ] **분석 모델 배치 방식** — 온프레미스 우선. 외부 API 사용 시 마스킹 선행

## 개발 사항

- [ ] 사진 업로드 (FR-4.1) — 다중 업로드, 용량·형식 검증
- [ ] `PhotoStorageAdapter` 구현 — 오브젝트 스토리지, presigned URL
- [ ] EXIF 추출 (FR-4.2) — GPS, `GPSImgDirection`, 초점거리 → 화각
- [ ] EXIF 부재 시 수동 촬영 위치·방위 지정 UI
- [ ] 세그멘테이션 — 지면/잔디/수목/건물/사람 분리
- [ ] 인물 마스킹 (NFR-6)
- [ ] 호모그래피 정합 (FR-4.4) — 픽셀 → 지도 좌표
- [ ] 장애물 검출 및 footprint 폴리곤화 (FR-4.3)
- [ ] 가용 영역 폴리곤 산출 (FR-4.5)
- [ ] 다중 사진 결과 병합
- [ ] `PhotoAnalysisAdapter` 구현 (`PhotoAnalysisPort`)
- [ ] `AnalyzeSiteService` 구현
- [ ] `TerrainRepository` PostGIS 저장
- [ ] 라우터 `POST /venues/{id}/photos`, `POST /venues/{id}:analyze`
- [ ] 웹: 사진 업로드 + 분석 결과 폴리곤 오버레이 + **수동 보정 편집기**

## 검증할 사항

- [ ] **지상 기준점 5개로 정합 오차 측정 — 5m 이내** (핵심 판정 기준)
- [ ] EXIF 없는 사진에서 수동 지정 경로가 끝까지 동작한다
- [ ] 경사지 사진에서 신뢰도가 실제로 낮게 나오고 UI 에 경고가 뜬다
- [ ] 사진 속 인물이 마스킹된 뒤에 외부로 나간다 (외부 API 사용 시)
- [ ] 사진 10장 분석이 5분 이내 (NFR-2)
- [ ] 같은 사진 → 같은 폴리곤 (NFR-3, 모델 시드 고정)
- [ ] 장애물 폴리곤이 가용 영역과 겹치지 않는다 (기하 무결성)
- [ ] 손상된 이미지·비이미지 파일 업로드가 안전하게 거부된다
- [ ] 저장된 사진에 접근 권한 검사가 걸린다 (presigned URL TTL)

## 반영되는 기능

- **FR-4.1** 현장 사진 다중 업로드
- **FR-4.2** EXIF 촬영 위치·방위·화각 추출 (+ 수동 지정 폴백)
- **FR-4.3** 장애물 검출
- **FR-4.4** 사진 → 지도 좌표 정합
- **FR-4.5** 가용 영역 폴리곤 산출
