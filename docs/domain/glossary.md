# 용어사전 (Ubiquitous Language)

코드·문서·대화에서 **같은 단어를 같은 뜻으로** 쓰기 위한 목록.
새 용어가 생기면 여기 먼저 추가하고 코드에 반영한다.

## 공연

| 용어 | 코드 | 뜻 |
|---|---|---|
| 공연 | `PerformanceEvent` | 장소 선정의 기준이 되는 행사 한 건 |
| 공연 일정 | `PerformanceSchedule` | 일자 + 시작/종료 시각 + 셋업/철수 시간 |
| 무대 요구사항 | `StageRequirement` | 무대 형태와 물리 규격, 전원·차량 진입 필요 여부 |
| 무대 형태 | `StageType` | 정면형(proscenium) / 돌출형(thrust) / 사방형(arena) |

## 장소

| 용어 | 코드 | 뜻 |
|---|---|---|
| 후보지 | `VenueCandidate` | 공연 가능성을 검토 중인 장소 한 곳 |
| 부지 경계 | `Polygon` (`boundary`) | 후보지의 실제 경계선 |
| 접근성 | `AccessProfile` | 대중교통 거리, 주차 대수, 차량 진입 가능 여부 |
| 지면 유형 | `GroundType` | 잔디 / 아스팔트 / 흙 / 데크 |

## 환경

| 용어 | 코드 | 뜻 |
|---|---|---|
| 태양 궤적 | `SolarTrack` | 공연 시간대 전체의 태양 위치 변화 |
| 태양 고도 | `altitude_deg` | 지평선 기준 각도. 음수면 일몰 이후 |
| 방위각 | `Bearing` | 진북 기준 시계 방향 각도 (0~360) |
| 역광 | glare | 관객이 무대를 볼 때 태양을 정면으로 마주보는 상태 |

## 현장 답사

| 용어 | 코드 | 뜻 |
|---|---|---|
| 답사 사진 | `SitePhoto` | 현장에서 찍은 사진 한 장 |
| 촬영 자세 | `PhotoPose` | 사진을 찍은 위치·방위·화각. EXIF 에서 추출 |
| 지형 분석 | `TerrainAnalysis` | 사진들을 종합한 가용 영역 + 장애물 정보 |
| 가용 영역 | `usable_area` | 무대·관객석을 놓을 수 있는 평탄한 빈 영역 |
| 장애물 | `Obstacle` | 배치 시 피해야 할 대상 (수목·전주·건물·경사·수면) |
| 정합 | registration | 사진 픽셀 좌표를 지도 좌표로 변환하는 것 |

## 배치

| 용어 | 코드 | 뜻 |
|---|---|---|
| 배치안 | `LayoutPlan` | 무대 + 관객 구역 + 통로를 합친 하나의 안 |
| 무대 배치 | `StagePlacement` | 무대의 위치·방향·크기 |
| 무대 정면 방향 | `facing` | 무대가 관객을 바라보는 방위 |
| 관객 구역 | `SeatingZone` | 관객을 나눠 배치하는 단위 영역 |
| 시야선 | `SightLine` | 특정 관객 지점에서 무대가 보이는 정도 |
| 시야각 | `horizontal_angle_deg` | 무대 정면 기준 관객 위치의 이탈 각도 |

## 평가

| 용어 | 코드 | 뜻 |
|---|---|---|
| 평가 축 | `Criterion` | 적합도를 구성하는 개별 항목 |
| 축별 점수 | `CriterionScore` | 원값 + 정규화값 + 가중치 + **근거 문장** |
| 적합도 | `SuitabilityScore` | 축별 점수의 가중 합산. 항상 근거를 함께 들고 다닌다 |

## 이 프로젝트에서 쓰지 않는 말

| 쓰지 않음 | 대신 | 이유 |
|---|---|---|
| 장소, 위치 (모호) | 후보지 / 좌표 / 배치 위치 | 셋이 전혀 다른 개념 |
| 좌석 | 관객 구역 | 고정 좌석 구조물은 범위 밖 |
| 최적 (단정) | 적합도 상위 | 점수는 가중치에 따른 상대값 |
