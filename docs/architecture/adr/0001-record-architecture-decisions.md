# ADR-0001. 아키텍처 결정을 ADR 로 기록한다

- 상태: 채택
- 일자: 2026-09-05

## 맥락

6주 안에 6개 스프린트를 도는 동안 되돌리기 어려운 결정이 여러 번 나온다.
"왜 이렇게 했더라"를 3주 뒤에 다시 논쟁하면 그 자체가 일정 리스크다.

## 결정

되돌리기 어렵거나 비용이 큰 결정은 `docs/architecture/adr/NNNN-제목.md` 로 남긴다.

- 형식: 맥락 / 결정 / 결과 / 대안
- 상태: 제안 → 채택 → 폐기(대체 ADR 번호 명시)
- **기존 ADR 은 수정하지 않는다.** 생각이 바뀌면 새 ADR 로 대체한다.

## 결과

- 결정의 이유가 코드와 같은 저장소에 남는다.
- PR 리뷰에서 "이건 ADR 감이다"라고 말할 공통 기준이 생긴다.

## 대안

- 위키 — 코드와 분리되어 낡는다.
- 커밋 메시지 — 검색은 되지만 한 곳에 모이지 않는다.
