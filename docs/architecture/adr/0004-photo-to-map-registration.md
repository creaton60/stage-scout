# ADR-0004. 사진-지도 정합은 지면 평면 가정 + 호모그래피로 한다

- 상태: 제안 (S1 스파이크로 검증 후 확정)
- 일자: 2026-09-05

## 맥락

이 시스템 전체가 걸린 기술 리스크다. 현장 사진의 픽셀 좌표를 지도 좌표로 바꾸지 못하면
"사진 기반 배치"라는 제품 정의 자체가 성립하지 않는다.

가진 정보는 EXIF 의 GPS 좌표, 방위(`GPSImgDirection`), 초점거리뿐이다.
깊이 센서도, 다중 시점 촬영 보장도 없다.

## 결정

**지면을 평면으로 가정하고 호모그래피로 투영한다.**

1. EXIF 로 카메라 위치·방위·화각을 얻는다.
2. 지면 평면을 가정해 픽셀 ↔ 지면 좌표 호모그래피 행렬을 구한다.
3. 세그멘테이션한 지면·장애물 마스크를 그 행렬로 투영해 폴리곤화한다.
4. `TerrainAnalysis.confidence` 로 신뢰도를 함께 반환하고, UI 에 항상 노출한다.

부지 경계는 Naver Map 이 주지 않으므로 **공공데이터 연속지적도**로 보강하고,
그것도 없으면 **사용자 수동 폴리곤 입력**으로 폴백한다.

## 결과

**성립 조건**
- 지면이 대체로 평면일 것 → 경사지에서 오차가 커진다. UI 에 경고를 띄운다.
- EXIF 방위가 있을 것 → 없으면 사용자가 지도에서 촬영 방향을 직접 지정한다.

**받아들이는 한계**
- 절대 정확도를 보장하지 않는다. 이 시스템은 **초안 배치도**를 만들고,
  최종 확정은 사람이 한다. 문구도 "최적"이 아니라 "적합도 상위"로 쓴다 (용어사전 참고).

## 대안

- **SfM / 다중 시점 3D 복원** — 정확하지만 촬영 부담이 크고 6주에 안 들어간다.
- **드론 정사영상** — 가장 정확하나 장비·비행 허가가 필요해 범위 밖.
- **수동 입력만** — 확실하지만 제품 가치가 사라진다.

## 검증 계획 (S1 스파이크)

실제 공원 사진 5장으로 정합을 시도해 **지상 기준점 오차 5m 이내**면 채택 확정.
초과하면 S4 를 "수동 폴리곤 편집 + 사진 참조" 로 축소하고 이 ADR 을 대체한다.
