# application — 유스케이스 레이어

"이 시스템이 무엇을 할 수 있는가"를 정의하고, 그 절차를 **조율**한다.
계산은 도메인에, 실제 I/O 는 어댑터에 맡기고 여기서는 순서만 잡는다.

## 구성

| 경로 | 뜻 | 방향 |
|---|---|---|
| `port/inbound/` | 바깥이 우리를 부르는 창구 (유스케이스 인터페이스) | 바깥 → 안 |
| `port/outbound/` | 우리가 바깥을 부르는 창구 (지도·기상·비전·DB) | 안 → 바깥 |
| `usecase/` | 인바운드 포트의 구현체 | |

## 의존 규칙

- `domain` 만 import 한다. `adapter` 는 절대 import 하지 않는다.
- 아웃바운드 포트는 `typing.Protocol` 로 선언한다 — 구현체를 상속시키지 않아
  어댑터가 application 을 역으로 import 할 일이 없다.
