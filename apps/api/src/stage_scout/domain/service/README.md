# 도메인 서비스

한 엔티티에 담기 어려운 **순수 계산 규칙**만 둔다.
I/O·프레임워크·외부 API 호출은 여기에 들어올 수 없다 — 필요한 데이터는 전부 인자로 받는다.
그래서 이 디렉터리의 모든 함수는 목(mock) 없이 단위 테스트할 수 있어야 한다.

| 모듈 | 책임 | 도입 스프린트 |
|---|---|---|
| `suitability.py` | 후보지 적합도 가중 합산 | S3 |
| `glare.py` | 태양 궤적 대비 무대 방향의 역광 판정 | S3 |
| `stage_orientation.py` | 제약 조건을 만족하는 무대 방향 후보 산출 | S5 |
| `sight_line.py` | 관객 지점의 시야각·가림 판정 | S5 |
| `capacity.py` | 구역 면적 → 수용 인원 환산(입석/좌석 밀도) | S5 |
