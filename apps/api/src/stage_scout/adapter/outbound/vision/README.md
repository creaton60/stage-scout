# 사진 분석 어댑터 (`PhotoAnalysisPort` 구현)

현장 사진에서 **가용 영역**과 **장애물**을 뽑아 지도 좌표로 정합한다.

## 파이프라인 (S4)

1. **EXIF 추출** — GPS 좌표, 방위(`GPSImgDirection`), 초점거리 → 화각
2. **세그멘테이션** — 지면/잔디/수목/건물/사람 클래스 분리
3. **좌표 정합** — 지면 평면 가정 + 호모그래피로 픽셀 → 지도 좌표 투영
4. **폴리곤화** — 가용 영역 외곽선, 장애물 footprint 산출

## 구현 선택지

- 1순위: 온프레미스 세그멘테이션 모델 (사진에 위치정보가 담기므로 외부 전송 최소화)
- 대안: 외부 비전 API — 이 경우 개인정보(행인 얼굴) 마스킹을 선행

두 경우 모두 `PhotoAnalysisPort` 뒤에 숨으므로 유스케이스 코드는 바뀌지 않는다.
